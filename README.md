# Thông Ngữ

Ứng dụng dịch văn bản với 16 lựa chọn ngôn ngữ.

## Chạy trên Windows

1. Tải ZIP và giải nén toàn bộ vào một thư mục.
2. Mở `Mo Thong Ngu.cmd` hoặc mở trực tiếp `index.html` bằng Chrome hoặc Edge.
3. Chọn ngôn ngữ nguồn và đích, nhập nội dung hoặc mở tệp UTF-8 .txt, rồi bấm **Dịch văn bản**.

Cần Internet để gửi nội dung cần dịch đến MyMemory. MyMemory áp dụng hạn mức dịch riêng.
